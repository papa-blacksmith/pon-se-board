# PON! SE Board v2 — ぷにぷに版

v1の機能を維持したまま、見た目を「ぷにぷに・肉球・まんまる」方向に更新した版です。

## v2変更点
- 36ボタンをより立体的なゼリー/グミ風に変更
- 押した時に潰れて戻る「ぷにっ」アニメーション
- 「ぷに四角」「まんまる」「肉球」の3形状を混在
- 各SEの編集画面から形状を自由に変更可能
- 肉球ボタンは4つの指＋中央パッドのシルエット
- v1で登録したSE/名前/音量/色は同じブラウザなら引き継ぎ
- Service Workerのキャッシュをv2へ更新

## GitHubでの更新
このZIPの中身を、既存の `C:\papa\pon-se-board` に上書きコピーしてください。
その後 GitHub Desktop で変更をCommitして Push origin します。
GitHub Pagesは既に設定済みなら設定し直す必要はありません。

更新後、古い見た目が残る場合はページを再読み込みしてください。PWAでは一度閉じて再起動すると反映されやすいです。
