# PON! SE Board

配信用のかわいい36ボタンSEサウンドボードです。

## 主な機能
- 36個のSEスロット
- 各スロットに音声ファイル、名前、絵文字、色、個別音量を保存
- タップで即再生
- SEの重ね再生・連打
- ALL STOP
- マスター音量
- 編集モード
- 長押し設定
- 編集モード時のドラッグ並び替え（PC/一部タブレット）
- IndexedDBに音声を端末保存
- PWA対応

## 起動方法
PWA機能を使うため、単に index.html をファイルとして開くのではなく、
HTTPSでホスティングするか、ローカルHTTPサーバーから開いてください。

例:
python3 -m http.server 8080

その後 http://localhost:8080/cute-se-board/ を開きます。

公開する場合は GitHub Pages / Cloudflare Pages / Netlify 等の静的ホスティングで利用できます。

## iPhone / iPad
Safariで公開URLを開く → 共有 →「ホーム画面に追加」

## Android
Chromeで公開URLを開く → メニュー →「ホーム画面に追加」または「アプリをインストール」

## 注意
音声ファイルは端末内ブラウザストレージに保存されます。
ブラウザデータ削除・プライベートブラウズ等では消える可能性があります。
